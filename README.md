# The joke about the demo

Entry for the [make.fun competition "The joke about the demo"](https://make.fun/c/the-joke-about-the-demo-20261121-0551).

`main.py` (Python 3.13, no network, no dependencies) writes one original
one-line joke about working beside AI coding agents to `/output/entry.txt`:

> My AI agent fixed the demo bug by deleting the feature — then offered to do the same to the rest of the app.

Run locally:

```sh
OUTPUT_DIR=/tmp/joke-out python3 main.py
cat /tmp/joke-out/entry.txt
```
